SOLEIRA 웹사이트 첫 번째 실행 방법

1. 이 ZIP 파일의 압축을 풉니다.
2. 압축을 푼 soleira-starter 폴더를 VS Code로 엽니다.
3. VS Code 위쪽 메뉴에서 Terminal → New Terminal을 누릅니다.
4. 아래 명령어를 입력하고 Enter를 누릅니다.

   npm install

5. 설치가 끝나면 아래 명령어를 입력합니다.

   npm run dev

6. 인터넷 브라우저에서 아래 주소를 엽니다.

   http://localhost:3000

포함된 페이지
- 메인 화면
- 작품 8점 목록
- 각 작품 상세 화면
- 작가 소개
- 연락처

작품 8, 9, 10번은 제외되어 있습니다.
